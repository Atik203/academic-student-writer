# Detector Log (maintainers and detector-specific questions only)

Read this file only when a user asks about a specific product/report or detector accuracy. Vendor information changes quickly.

**Last checked:** 2026-10-24. Status labels describe the source of the information, not an independent validation of detector performance.

- **OFFICIAL RELEASE NOTE**: confirmed that the product vendor documents a release/update and its stated purpose.
- **VENDOR CLAIM**: performance/accuracy statement made by the vendor; not independently replicated here.
- **INDEPENDENT STUDY**: peer-reviewed or primary research finding, scoped to the study's dataset and methods.
- **MAINTAINER INFERENCE**: interpretation, not a vendor-verified mechanism.

## Maintenance rules

For each update, record the date checked, official URL, source's own publication/update date, product/model version if stated, what changed, and whether the statement is an official release note, vendor performance claim, independent finding, or maintainer inference. Do not infer that a prose pattern causes a detector label unless a source establishes that relationship. Do not treat a single detector score screenshot or anecdote as reliable evidence.
